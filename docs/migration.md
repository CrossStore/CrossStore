# 迁移与验收

2026-10-23：21 个应用入口均提供 Lua 安装包。旧 C++ 应用源码保存在包内 `native/`，用于来源追溯和传统固件。迁移指界面、交互与轻量应用规则进入 Lua；不表示网络协议、图像解码、书籍解析也改用 Lua。

| 范围 | 已实现 | 当前差异与验证边界 |
| --- | --- | --- |
| 启动器与商店 | 已安装应用列表/网格，独立商店入口，源地址、只读硬件信息、逐项权限 | Mono 已确认启动及入口正常；刷固件不会自动更新已安装包 |
| 游戏与计算器 | 独立棋盘、计算器显示区、触摸/按键、存档；五子棋、象棋的轻量 AI | 不迁移旧原生游戏存档；象棋非原版深搜索 AI，数独题库难度较少 |
| 木鱼 | 计数、短促蜂鸣器声音、静音开关 | Mono 的 buzzer 与 speaker audio 是两项能力；实际声音尚待用户确认 |
| 三种聊天 | Lua 会话、好友、发现、二维码、气泡、重试；授权后的清醒后台通知 | 原生传输已完成过双机测试，新 Lua 页面仍需分别复测三种传输 |
| 设备宠物与阅读统计 | 确定性设备宠物；已有阅读统计、历史与继续阅读 | 统计成就/资料等完整原版页面未全部重现；首次认领状态与旧界面独立 |
| 随机头像 | Lua 程序化头像、种子保存、流式 SVG 导出 | SVG 替代原版 BMP；算法与原始随机头像不逐像素等价 |
| 待机时钟 | 钟面、反色、月历、农历、节气、联网校时 | 需要 keep_awake；目前是保持唤醒按分钟刷新，不宣称省电；未移植 C3 轻睡眠策略 |
| 像素画布 | 四灰阶公共画布、实时快照、选点/调色/坐标输入、限速合并发送 | 宿主使用模拟快照检查 UI；没有向公共画布发送测试像素 |
| AirPage | 上传二维码、实时接收、历史、原生灰阶图片显示、壁纸 | 延用原有恢复缓存；需要实机验证上传、断网恢复和图片灰阶 |
| 微信读书 | 账户登录、书架、详情、简介分页、章节范围、下载、打开本地书 | 在线边读边取、封面墙、缓存管理仍需完善；登录及真实账户下载未在本轮实测 |
| 书库/传输/OPDS | Lua 包作为核心入口 | 阅读器和文件传输属于系统服务，继续由 C++ 实现 |

宿主验证使用真实 Lua 运行时，覆盖 336×430、432×640、912×420、492×850 的可用画布；联网 UI 使用模拟服务，不等同于真实服务器测试。农历、闰月及节气对照原生实现检查，保留原算法的近似精度。

API 3 发布后，旧运行时会跳过不支持的新包，仍可更新原有 API 2 应用。应用包的 `status: ready` 表示包可安装执行，不等于所有硬件和网络服务验收均已完成。
