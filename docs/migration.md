# 迁移与验收

2026-10-23：21 个应用入口均提供 Lua 安装包。旧 C++ 应用源码保存在包内 `native/`，用于来源追溯和传统固件。迁移指界面、交互与轻量应用规则进入 Lua；不表示网络协议、图像解码、书籍解析也改用 Lua。

| 范围 | 已实现 | 当前差异与验证边界 |
| --- | --- | --- |
| 启动器与商店 | 已安装列表/网格、独立商店入口、源地址/硬件/权限；API 5 配套固件显示目录总数/双向翻页和升级要求 | Mono 已确认旧版启动与入口；新版分页待实机确认；刷固件不会自动更新已安装包 |
| 游戏与计算器 | 独立棋盘、显示区、触摸/按键、存档；五子棋双尺寸/三档 AI/执黑白/统计；数独三档题库/提示/计时/统计 | 两包保留旧 Lua 档读取；不迁移原生二进制档；五子棋和象棋非原版深搜索，数独为有限种子库 |
| 木鱼 | 计数、声音/静音；配套 S3 固件使用内置木鱼 PCM 采样 | Mono 之前的提示音已确认；新版 PCM 听感待确认；接口不播放任意 MP3/WAV 文件 |
| 三种聊天 | Lua 会话、好友、发现、二维码、气泡、重试；授权后的清醒后台通知 | 原生传输已完成过双机测试，新 Lua 页面仍需分别复测三种传输 |
| 设备宠物与阅读统计 | 确定性宠物；阅读概览/月历热力图/日期书单/章节与日期详情/继续阅读/真实系统成就 | 画像、年度趋势、完整会话时间线、封面和手动时长修订未迁移；宠物首次认领状态与旧界面独立 |
| 随机头像 | Lua 程序化头像、种子保存、流式 SVG 导出 | SVG 替代原版 BMP；算法与原始随机头像不逐像素等价 |
| 待机时钟 | 钟面、反色、月历、农历、节气、联网校时 | 需要 keep_awake；目前是保持唤醒按分钟刷新，不宣称省电；未移植 C3 轻睡眠策略 |
| 像素画布 | 四灰阶公共画布、实时快照、选点/调色/坐标输入、限速合并发送 | 宿主使用模拟快照检查 UI；没有向公共画布发送测试像素 |
| AirPage | 上传二维码、实时接收、历史、原生灰阶图片显示、壁纸 | 延用原有恢复缓存；需要实机验证上传、断网恢复和图片灰阶 |
| 微信读书 | 登录、书架/详情、简介、章节范围、下载、本地书；新增本地章节目录/缓存状态、按书恢复图片选项 | 在线边读边取、封面墙、书评/划线、缓存删除未迁移；登录及真实下载未在本轮实测 |
| 书库/传输/OPDS | Lua 包作为核心入口 | 阅读器和文件传输属于系统服务，继续由 C++ 实现 |

宿主验证使用真实 Lua 运行时，覆盖 336×430、432×640、912×420、492×850 的可用画布；联网 UI 使用模拟服务，不等同于真实服务器测试。农历、闰月及节气对照原生实现检查，保留原算法的近似精度。

API 5 配套商店会列出格式有效但需要更新固件的条目并说明原因；旧运行时可能直接跳过不支持的新包。这与第一页只有 16 项、Apps 首页只显示已安装包一起，都会造成「应用较少」的观感。当前目录仍是 21 个入口，本轮主要补齐已有应用的功能。`status: ready` 表示包可安装执行，不等于所有硬件和网络服务验收均已完成。

2048 0.3.0 要求 API 4 的 `on_stop`：合并保存移动，正常退出和休眠前补存，沿用原有 `game` / `best` 存档格式。未升级固件的设备继续使用已安装的 0.2.0；升级固件与更新应用包是独立步骤。

五子棋、数独 0.3.0 同样需要 API 4，采用 2 秒空闲/10 秒检查点/退出补存，写入失败保留待存状态。阅读统计 0.3.0、微信读书 0.4.0 需要 API 5 的只读宿主查询。四包均保留原有 2/4/16 灰阶图标。

本轮新增的宿主测试覆盖数独题库唯一解/分级、满候选笔记与撤销，五子棋 225 手满棋盘读档/保存，阅读统计稀疏日期游标/长标题，微信读书 5000 章索引/损坏缓存。它们使用实际受限 Lua VM，但替换了设备服务；不能代替卡速、网络、屏幕和实体输入的实机验收。阅读统计、数独与五子棋仍使用 64 KiB VM 上限，压力测试触发垃圾回收，不能据此宣称有额外内存余量。
