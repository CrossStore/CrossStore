# 阅读统计

`0.3.0` 需要 CrossMux Lua API 5，以及用户授予 `reading_data` 权限。应用只读取系统已经记录的数据，不修改阅读时长、日期或成就。

- 概览：今日/累计/近七天时长、读完数量、连续达标天数。
- 书籍：分页浏览，查看进度、章节、阅读次数、上次时长、首次/最近/完成日期，并交给系统阅读器继续阅读。
- 日历：按月的灰阶热力图，点击日期选择，再进入当日书单；实体按键也能通过上一天/下一天与日期详情进入。
- 成就：读取系统真实的解锁状态与解锁日期，区分未完成/已解锁。尚未解锁的成就显示目标；不会推算或伪造当前完成量。

使用原有 2/4/16 灰阶图标。所有布局使用宿主提供的画布尺寸，触摸区域和绘制共用几何位置。

## 资源与查询

Lua 内存上限仍为 64 KiB。一次只保存最多 7 行书籍数据；日期时长从系统的有序历史中二分查询。日期书单的单次宿主调用最多检查 32 本书，每页最多调用 7 次，有剩余数据时继续翻页。没有将完整历史或完整成就表复制到 Lua，也没有应用自己的存档或写卡操作。

日历使用配置的本地日期，与系统阅读统计共享日期边界。没有可信时间、也没有任何带日期的历史时，显示说明，不虚构月份或数据。旧记录可能只有每日总时长，因此日期总时长不一定都能归属到某一本书。

## 尚未迁移

阅读画像/雷达图、年度趋势图、完整会话时间线、封面与手动时长修订仍未实现。成就的解锁逻辑和数据持久化继续由 CrossMux 核心负责；本应用不会触发统计重建、重置或成就解锁弹窗。

## 验证

在 CrossMux 仓库运行：

```sh
python3 test/crossstore/test_reading_stats_migration.py ../CrossStore/packages/reading_stats/main.lua
```

该测试使用固件实际的 Lua VM，覆盖四种画布尺寸、中英文、64 KiB 限额、稀疏的日期书单、前后翻页、最长宿主标题、权限拒绝、关闭成就及空历史。硬件验收：打开有阅读记录的日期，核对总时长/书籍/继续阅读；检查不同灰阶设备的月历与触摸位置。
