# 微信读书

0.4.0 需要 CrossMux Lua API 5。Lua 负责书架、详情、下载选项和章节缓存界面；登录、网络协议、下载事务和阅读器由固件服务提供。

在书架打开一本书后：

- 「本地章节」分页显示目录，每页最多 7 章，并区分已有章节文件、尚未缓存和读取失败；付费标记沿用缓存目录。
- 「下载选项」可选择保留图片或纯文字，以及全书或章节范围。重新进入一本书时，图片选项恢复为上次下载保存在卡中的选项；只浏览或切换选项不会写卡或联网。
- 「阅读缓存」打开已有 EPUB。章节文件存在不代表已经成功生成可阅读的 EPUB，两种状态分别显示。
- 下载完成后回到图书详情，更新离线状态。目录损坏时显示重试提示，不自动清理缓存或删除书籍。

本地章节页面不会发起联网，也不会逐章读取正文。它复用固件的 SD 目录索引，保留一个文件句柄与一条章节记录。菜单中的「阅读书籍」打开书籍，并非跳到列表中的指定章节。

当前仍未迁移封面墙、书评/划线浏览、缓存删除管理；不提供在线边读边取。开发验证使用隔离的模拟服务，没有访问真实账户或进行在线下载。

宿主验证：

```sh
python3 ../crossmux/test/weread_cache/test_weread_cache.py packages/weread/main.lua
```

验证覆盖目录分页、选项往返与按书恢复、损坏/缺失缓存反馈、下载完成返回详情、权限拒绝，以及四种画布尺寸。模拟存储测试检查实际缓存拥有者的索引范围、读失败和生命周期。真实卡的读取速度、账号登录和真实下载仍需实机确认。
